# CK2 高亲和力候选的 SA 分层与 SynCraft 验证

日期：2026-10-15。数据来自此前 `main1000_w050/single` 的 1,000 个终态；本次没有重新生成源分子。新增 6 次真实 `deepseek-flash` 调用。结论：**高亲和力集合确实包含 SA 相对较差的分子，但 SA 最高的几个同时有高构象应力；通过原有完整质量筛选的集合没有 SA≥3 的分子。**

## 1. 优质集合的定义与统计

沿用此前 CK2 分析的门槛，不根据本次 Agent 的结果修改规则：

1. 在 961 个有效、连通的生成粒子中，取预测 pIC50 的上十分位：`pic50_on_rescore ≥ 8.1350488663`。
2. 严格质量集合进一步要求完整 PoseBusters 通过、MMFF 局部松弛收敛、`mmff_relief_per_heavy ≤ 0.7398986221 kcal/mol/重原子`。应力门槛为原有效粒子集合的 Q75，是本项目经验门槛。
3. 按 canonical isomeric SMILES 去重；每个集合内部选亲和力最高的合格构象，同分时按局部应力、ID 排序。先检查构象资格，再去重。不合并互变异构体、质子化状态。

高亲和力的 97 个粒子中，83 个通过完整 PB；其余 14 个均在 `internal_energy` 检查失败。30 个不满足局部应力门槛，其中包含这 14 个 PB 失败粒子；97 个的局部松弛均收敛。PB 的能量规则和本项目连续应力门槛并不等价，因此 PB 通过也可能有较高应力。

`pic50_on_rescore` 是 FLOWR affinity head 对同一 decoded state 在 t=0.9999 的重评分，尚未经过独立实验校准，也不是本次新做的 docking。局部应力是同一化学图在 H-only preparation 后进一步局部松弛的能量下降，再除以重原子数；它不是结合自由能，也不是相对于全局最低能构象的真实应变能。下表同时保留原记录的 `strain_MMFF94s_kcal_mol`，两种能量处理口径不能混用。

SA 使用 1–10 原始方向，越低越容易；SA≥3、≥4 在这里用于描述分层，不是合成可行性的硬标签。其片段频率和结构复杂度指标不能代替逆合成路线。[SA 原始论文](https://link.springer.com/article/10.1186/1758-2946-1-8)

## 3. 已执行的 SynCraft 核心框架验证

配置：SynCraft-Core revision `557703e110b26a354afed2955ded5217837f6692`，使用其真实案例检索、格式化与图重构函数；5 个检索示例，排除验证源图；EvoMolSteer API 的 `deepseek-flash`，每个分子 1 个提案，temperature=0，最大输出 4096 token。约束为最多 6 个操作、增加/删除原子各不超过 2、Morgan Tanimoto≥0.5。无化学失败后的重采样，无路线反馈，也未引入生成轨迹。

| ID | 实际提出的修改 | 编辑结果 | SA：原分子 → 新分子 | ΔSA（原−新，正为改善） | 相似度 |
| --- | --- | --- | --- | ---: | ---: |
| b017_final_021 | 删除芳环上的 Cl | 接受 | 2.9783 → 2.7734 | +0.2049 | 0.732 |
| b004_final_020 | 羧酸 → 伯酰胺 | 接受 | 2.9549 → 2.9855 | −0.0306 | 0.836 |

| b011_final_017 | 羧酸 → 醛 | 接受 | 4.0512 → 4.2351 | −0.1839 | 0.696 |
| b000_final_034 | 删除环上 6 个原子 | 拒绝：超出删除预算 | 4.0221 → 未生成合格产物 | — | — |
| b011_final_016 | 删除外环 NH₂ | 接受 | 3.9817 → 3.8925 | +0.0891 | 0.661 |

质量组 2/3 改善，平均 ΔSA=+0.1172；挑战组 1/3 改善，两个合格产物平均 ΔSA=−0.0474。若把被拒绝编辑记为零收益，挑战组三个任务平均 ΔSA=−0.0316。负收益完整保留，没有只报告改善的产物。

这组结果表明当前框架能执行局部修改，但对高 SA 核心的优化效果尚弱。观察到的原因包括：

- **修改集中在外周基团。** 两个质量组成功案例只是去氯；挑战组成功案例是去氨基，SA 下降有限。复杂环系构建困难并没有得到路线层面的解决。
- **“看起来更简单”不能保证 SA 降低。** 羧酸改为酰胺或醛后，SA 均上升。由原酸进一步转化得到产物的描述，也不能证明从可购原料出发的总路线更短。
- **解释仍有结构识别和约束遵循错误。** `b000_final_034` 的解释将含双键的环片段称为饱和 CH₂–CH₂ 桥，同时明确意识到删除 6 个原子超预算却仍提交。严格执行器阻止了该操作。
- **评价目标尚未闭合。** Agent 的“少一步氯化”“更易获得原料”等解释没有真实路线支持；去除 Cl 也不必然减少合成步骤。当前 SA 反馈只用于事后记录，未用于迭代改进。

6 次 API 均成功，6 次 HTTP 请求，服务端报告输入 22,670 / 输出 2,031 token。5 个合格产物中 3 个 SA 改善、2 个变差。所有产物的亲和力、三维构象和应力仍为 `not_evaluated`，逆合成为 `not_run`。这批结果是单轮小样本试验，不是 SynCraft 论文完整方案的复现，也不能验证生成轨迹的作用。

## 4. 用逆合成评价进一步选择优化对象

**建议首先对严格质量集合的全部 24 个独立图做逆合成，而不是继续提高 SA 入选阈值。** 这些分子 SA 虽低，仍可能因稠环构建、取代位置或原料覆盖等原因缺乏可行路线；这需要搜索结果验证。优先选择“亲和力和构象质量保留价值高、但路线存在明确瓶颈”的对象。

SynCraft 补充材料 §1.8 使用 SimpRetro、USPTO/RDChiral 模板、Enamine building blocks 和每分子单核 30 分钟预算。SimpRetro README 的示例库存是 eMolecules；二者不能直接视为相同协议。[SynCraft 补充材料](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs42256-026-01304-x/MediaObjects/42256_2026_1304_MOESM1_ESM.pdf) · [SimpRetro 官方仓库](https://github.com/catalystforyou/SimpRetro)

建议执行协议：

1. 固定 SimpRetro commit、模板哈希、原料库来源/版本/哈希、分子标准化规则、CPU 资源和每分子 1800 秒预算。先按 canonical graph 去重；不把不同互变异构体的搜索结果直接合并。
2. 先搜索 24 个质量图。搜索上限约 12 核时；若对全部 45 个高亲和力图搜索，上限约 22.5 核时。两份清单有重叠，选择一个范围或按图与协议缓存，避免重复计算。高应力分子单列，不能与质量组混算。
3. 分别记录 `route_found`、`no_route_within_budget`、`infrastructure_error`。超时未找到只能说明当前模板、原料库、算法和预算下未找到，不能宣称分子不可合成。工具启动失败不算难合成。
4. 对返回路线检查反应步骤、原子/立体信息、叶节点是否确实在库存、保护基和选择性。再记录步数、最长线性路径、未解决中间体及原料成本/可购性。当前适配器只解析搜索统计，`route_verified=False`；路线导出与化学验证仍需补充。
5. 对已找到且验证较短路线的分子，保留为容易对照；对已找到但路线冗长的分子，研究路线缩短；对质量合格但预算内未找到路线的分子，优先检查失败分支并提出小范围结构修改。
6. 在同一协议下重评原分子与产物，再对通过路线验证的修改做三维重建、独立结合评价和应力检查。不能将原分子的高 pIC50 和低应力继承给修改后的化学图。

将来比较 T 与 T+H 时，应在运行各方法前冻结逆合成选样及数据划分。用于选样的逆合成标签可以对 Agent 隐藏；如果把未解决分支作为反馈，则所有实验组应获得相同的路线反馈和预算。经验记忆的训练/测试应按骨架或生成谱系划分，避免相似分子泄漏。

本次工作区未发现可运行的 SimpRetro 安装、所需模板与已固定的原料库，因此未运行实际逆合成，没有生成任何“不可合成”标签。新增 `screen-retro` 直接调用独立逆合成端口，不加载 Agent、不消耗 LLM 调用；准备好外部运行时后可直接筛选冻结的目标清单。详见[示例运行说明](../examples/ck2_sa_validation/README.md)。

## 5. 代码与可复核性

- `agenticgen.cohorts`：沿用原阈值、按图去重、分层选样、原始 SDF 与 seed 校验、统计及逆合成目标导出。
- `agenticgen.retro_screen`：保持目标索引，分离搜索无解和基础设施失败，拒绝重复图，逐目标落盘。
- `scripts/summarize_ck2_sa.py`：从保存的决策重新计算分层结果，不重新调用 Agent。
- 测试：33 项通过；Ruff 检查通过。选样测试核对 45/24 个独立图、六个入选 ID、挑战组与质量组不重叠，以及源 SDF 字节和坐标保留。
